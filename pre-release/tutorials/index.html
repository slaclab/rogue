Tutorials

Tutorials provide guided, end-to-end learning paths.

Scope of Tutorials:

  • Build deeper understanding through complete workflows

  • Explain tradeoffs and design patterns, not just first use

  • Bridge into architecture-level sections after hands-on examples

New to Rogue? Start with Build Your First Rogue Application — it builds a complete working application from scratch with no hardware required.

Note

Every tutorial below runs without hardware. Rogue ships software endpoints — a memory emulator, an SRP emulator, a PRBS data generator — so each subsystem can be learned before a board is involved. Each tutorial’s code lives in docs/src/tutorials/examples/ and is executed by the test suite, so what you read is what runs.
